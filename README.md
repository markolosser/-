# سَكَن | Sakan

منصة عربية تجريبية تساعد الطلاب على استكشاف خيارات السكن والعثور على شريك سكن.

## تشغيل المشروع محليًا
لا يحتاج المشروع إلى تثبيت حزم أو إعداد build:

1. نزّل المستودع أو افتحه باستخدام VS Code.
2. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا مثل Live Server.

## النشر
الموقع مبني حاليًا كصفحة HTML/CSS/JavaScript ثابتة. يوجد workflow في `.github/workflows/pages.yml` لنشر الملفات على GitHub Pages عند الدفع إلى فرع `main`.

بعد تفعيل GitHub Pages واختيار **GitHub Actions** كمصدر للنشر من:
**Settings → Pages → Build and deployment → Source**،
سيتم نشر الموقع تلقائيًا مع كل تحديث على `main`.

## حدود النسخة الحالية
- بيانات الإعلانات التجريبية تُحفظ في `localStorage` داخل متصفح كل زائر؛ لا توجد قاعدة بيانات مشتركة.
- نماذج التواصل والحسابات ولوحة الإدارة ليست متصلة بخادم أو نظام مصادقة.
- لا تضع مفاتيح سرية أو بيانات اعتماد داخل ملفات الواجهة الأمامية.

## الخطوة التالية لنسخة إنتاجية
ربط Supabase أو backend موثوق لإدارة المستخدمين والإعلانات والصور، مع تفعيل سياسات Row Level Security (RLS) وصلاحيات الإدارة قبل استقبال بيانات حقيقية.
